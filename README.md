## Why This Repository Exists

The core **Bluecollar India** web application is currently in development and has not yet undergone security testing or code review. To avoid exposing an unfinished and untested codebase publicly, this separate landing page was created to:

- Establish an online presence at [bluecollarindia.com](https://bluecollarindia.com)
- Inform visitors that the platform is coming soon
- Serve as a placeholder while the main application is being built and tested

This approach keeps the production domain live and professional without compromising the security of the actual application.

---

## About Bluecollar India

**Bluecollar India** is a platform aimed at connecting blue collar workers with job opportunities across India.

The goal is to bridge the gap between skilled workers and employers by providing an accessible, easy-to-use platform tailored for the blue collar workforce.
